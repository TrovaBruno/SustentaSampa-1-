## Contexto do problema

O SustentaSampa nasceu da necessidade de monitorar zonas alagadas na cidade de São Paulo. Como a infraestrutura oficial de medição tem lacunas, o projeto usa dados colaborativos (*crowdsourcing*): os próprios moradores reportam alagamentos com foto e localização, e o sistema consolida isso em mapa de calor, indicadores de risco e relatórios por região. Os dados são cruzados com fontes abertas de clima e de nível de rios (Open-Meteo e ANA).
